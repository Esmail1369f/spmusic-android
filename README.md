# ساهره پلیر موزیک — SPMusic

سورس اولیه Flutter برای ساخت APK اندروید؛ APK نهایی هنوز تأیید نشده است.

## امکانات اولیه
- رابط فارسی راست‌چین با تم تیره و طلایی
- اسکن موسیقی محلی، جست‌وجو و نمایش کاور موجود
- پخش، توقف، قبلی/بعدی و نوار پیشرفت
- ذخیره علاقه‌مندی‌ها به‌صورت محلی

## ساخت APK
GitHub Actions تلاش می‌کند با هر push به شاخه main پروژه را تحلیل و APK دیباگ بسازد. پس از موفقیت، به Actions و سپس Artifacts بروید و SPMusic-debug-apk را دریافت کنید.

## هنوز تکمیل نشده
پخش پس‌زمینه و اعلان رسانه، ویژوالایزر واقعی، اکولایزر، تایمر خواب، فهرست‌های پخش و تنظیمات پیشرفته. نتیجه build و نصب باید جداگانه تأیید شود.
